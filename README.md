# Lumio (Mint & Gold)

## Run it (5 minutes)
1. Install Node.js 18+ from nodejs.org
2. In this folder: `npm install`
3. Get an API key at aistudio.google.com (free, no card needed)
4. Copy `.env.example` to `.env.local` and paste your key
5. `npm run dev` then open http://localhost:3000

## Deploy
Push to GitHub, import the repo on vercel.com, add `GEMINI_API_KEY` in Environment Variables, deploy.

## What works now
Landing, Dashboard (demo numbers), AI Tutor (streaming), 14 AI tools, dark/light theme.
